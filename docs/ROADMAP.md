# 下一批可独立认领的任务

| 负责人 | 任务 | 验收条件 |
| --- | --- | --- |
| A（前端） | 改善手机上两段歌曲语境的对照阅读与播放状态 | 窄屏可完成听句、答题、重试；刷新后状态一致；不支持的操作明确禁用。 |
| B（Agent/API） | 为非敏感学习会话加入持久化和 schema 迁移 | 服务重启后仍能恢复进度；重复提交保持幂等；标准答案不进入浏览器节点数据。 |
| C（媒体） | 系统验证 Mac「音乐」桥接的切歌、定位与暂停时延 | 记录真实成功和失败条件；不得把未播放显示为成功；Windows/Linux 离线检查继续通过。 |
| D（教学内容） | 试用并复核当前韩语、日语、中文原创跨语境样例 | 有来源、学习目标、选项依据、补教提示与一次真实学习者试用记录；三语均不得把未核对推断写成事实。 |

韩语、日语和中文固定原创课程已经具备可实际操控的 ASCII 歌词地下城、自动回听音符、三句听辨题、NPC 情境题、知识卡、噪声精灵、单字排序终局和幂等移动/答题服务端状态。真实同步歌词还能由专用地下城 Agent 决定关卡数、地图布局、实体组合和字符散布种子，再经工具校验与地图组装；结果明确未人工核对，动态课程只保留在当前内存并过期清理。随后优先增强不同歌曲的关卡主题差异、题目质量抽检和词形核对。目前歌词索引只能做连续字符检索；语言由用户选择而非自动识别，开放式语义评分、语音评分、多 Agent、大世界自由移动、影视或综艺检索都不属于这版已实现能力。
