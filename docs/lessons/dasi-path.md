## 节点说明

### 1. `demo-dasi` · 语境关

- **前置：**知道「다시」基本义。
- **题干：**第二首「내일 다시 이야기하자」里「다시」强调什么？
- **正解 (0)：**明天再次谈这件事。依据：`내일` + `이야기하자`，并与上一句昨天没说出口相连。
- **干扰：**从未说过（忽略「다시」与昨天句）；今天立刻结束（与「내일 / 이야기」矛盾）。
- **补教：**先看昨天句，再看明天句，找时间上的再次。

### 2. `demo-dasi-contrast` · 对照语境关

- **前置：**完成上一关。
- **题干：**比较两句「다시」分别连着怎样的再次。
- **正解 (0)：**再一起走路试试 / 再谈一次（未说完的事）。
- **干扰：**两句都只表示立刻结束；两句都表示第一次见面（抹平对照）。
- **补教：**并排看动词「걸어 볼까」与「이야기하자」。

### 3. `demo-dasi-final` · 最终挑战

- **前置：**完成对照关。
- **题干：**新句「시험은 어려웠지만, 다시 볼게。」中「다시」的合理理解。
- **正解 (0)：**会再考一次 / 再看一次这科考试。文本只支持「再次应试/再看」，不要求情绪结论。
- **干扰：**永远不再尝试（否定「다시」）；第一次见面（无关场景）。
- **补教：**圈出「시험」「볼게」，问重复的是哪个动作。
