# 肉鸽路径 V2 修改方案（评审稿）

> 针对反馈：① 单关题目太少，真实 Agent 是否也会这么少；② 路线过短过直，希望接近《杀戮尖塔》的长路径 + 血量/回血/角色等节点。
> 本文是**设计方案**，尚未改代码。确认后再改 `AGENT_OUTPUT_SPEC`、样本 JSON 与预览图。

---

## 1. 先回答两个问题

### 1.1 真实 Agent 输出也会这么少吗？

**不应该。** 当前预览里「一个地图点 = 一道选择题」是 **P0/P1 演示用的最小形状**，方便对齐字段，不是产品目标密度。

| 现状（样本） | 建议（V2） |
| --- | --- |
| 1 个 `mapNode` ≈ 1 题 | 1 个地图房间 = **题包 `encounter`**，内含 **3～8 题**（可配置） |
| Agent 一次生成整条短线 | Agent 按「层 / 房间」生成；或一次生成整局但房间内必须带 `items[]` 题列 |
| 规范未强制最小题量 | 规范增加：`context` / `elite` / `boss` 房间的 `minItems` / `maxItems` |

**结论：** 少题是样例偷懒，不是 Agent 上限。V2 用规范锁死「房间最低题量」，B 侧校验不达标的草稿直接打回。

### 1.2 要不要做成真·杀戮尖塔？

**机制上像，主题上仍是学语言。**
血量、回血、角色、遗物 = **学习状态的隐喻**，不要做成无意义的数值刷子；每个战斗向房间仍以歌词证据题为核心。

## 2. 目标体验（对齐尖塔的「长」）

```text
选一首歌（出发）
    ↓
第 1 层（约 6～8 个房间，有分叉）
    ↓ 层主
第 2 层（约 6～8 个房间，分叉更凶 / 题更难）
    ↓ 层主
第 3 层（更短冲刺 + 终局 Boss 题包）
```

- **总房间数（设计目标）：** 约 **18～24**（含休息、事件、商店），其中「战斗向」约 **10～14**。
- **玩家一局时长（预估）：** 25～45 分钟（可按题量再调）。
- **分叉：** 每层至少 **2～3 个** `player_choice` 分叉点（不是只在第一关后分一次）。

相对当前样本（5 点、一次三岔就汇合）会明显加长、加厚。

## 3. 核心概念改写

### 3.1 地图点 ≠ 一题

| 概念 | 含义 |
| --- | --- |
| **房间 `room`** | 地图上一个节点（尖塔里的一格） |
| **遭遇 `encounter`** | 房间内的一次内容；战斗房含多题 |
| **题目 `item`** | 单道 `context_choice` / 听辨填空等 |
| **局状态 `runState`** | 血量、护盾、角色、遗物、已学表达等 |

Agent 输出最小战斗房示例：

```json
{
  "id": "f1-r3",
  "roomType": "combat",
  "mapNode": "context",
  "personaId": "polysemy_tutor",
  "encounter": {
    "title": "窗边 · 义项扫荡",
    "minItems": 4,
    "items": [ /* 4～6 道题，共享本房证据句池 */ ]
  }
}
```

### 3.2 房间类型（尖塔映射）

| 尖塔感 | `roomType` | 学习含义 | 建议题量 |
| --- | --- | --- | --- |
| 小怪 | `combat` | 一词多义 / 语境小题包 | **4～6** |
| 精英 | `elite` | 跨歌对照 + 易混分叉，更刁钻 | **5～8** |
| Boss | `boss` | 层末 / 终局迁移大题包 | **6～10** |
| 休息处 | `rest` | 回血：复习错题 / 重听证据 / 选一题精讲 | 0～2（可选小测） |
| 未知事件 | `event` | 文化探索或 Galgame 短剧（有限选项） | 探索为主，可不判血 |
| 商店 | `shop` | 用「洞察点」换提示卡、跳过券、换 persona 助战 | 无战斗题 |
| 宝箱 | `treasure` | 获得遗物（被动加成）或学习小卡片 | 无战斗题 |
| 问号岔路 | `fork_only` | 纯选择下一房间（也可并入边上的 choice） | — |

### 3.3 血量 / 回血 / 资源（学习隐喻）

| 字段 | 建议规则 | 注意 |
| --- | --- | --- |
| **`hp` / `maxHp`** | 默认 3～5；答错一题 −1；归零则本局失败或强制休息 | 不是暴力游戏，UI 文案用「专注值 / 理解耐力」 |
| **回血 `rest`** | 休息房：+1～2 HP，或清除一层「易错标记」 | 每层休息房有限（尖塔感） |
| **护盾 `shield`** | 遗物提供：下一题容错一次 | 可选 P1.5 |
| **洞察点 `insight`** | 答对积累；商店消费 | 替代金币 |
| **连对 `streak`** | 连对 3 题可临时减伤或加洞察 | 激励认真读证据 |

**规范约束：** 扣血必须绑定「可复核的答错」；禁止随机掉血。

### 3.4 角色与「遗物」

**出发选角色（persona 进阶，开局三选一）：**

| `characterId` | 定位 | 开局加成（例） |
| --- | --- | --- |
| `polysemy_tutor` | 义项侦探 | 对照题多给一句证据提示 |
| `story_npc` | 剧情旅人 | 事件房选项多一条安全支线 |
| `culture_guide` | 文化向导 | 开局带 1 张文化卡片；文化房不耗洞察 |
| `listening_coach` | 听感教练 | 有音源时听辨房 −1 难度（无音源则禁用） |

**遗物 `relics[]`（宝箱/精英掉落，示意）：**

| 遗物 | 效果 |
| --- | --- |
| 双色便签 | 对照关自动显示 `contrastAxis` |
| 消歧小刀 | 本层第一次答错不扣血 |
| 回声贝 | 允许重听当前证据句一次（依赖 C） |
| 怀疑眼镜 | 导师质疑房更容易辨伪 |

角色与遗物都是 **Agent 可生成的枚举内 id**，效果表由你（D）锁定，模型不得自造数值外效果。

## 4. 单层路线怎么「像尖塔」

每层推荐拓扑（示意）：

```text
        [战斗]
       /      \
  [战斗]      [事件]
     |    \    /   \
  [精英]   [休息]  [商店]
       \    |    /
        [战斗]
           |
         [Boss]
```

生成规则（写进规范给 Agent / 校验器用）：

1. 每层 **至少 1** 休息、**至多 2** 商店。
2. 精英 **1**；Boss **1**（层末）。
3. 从起点到 Boss 的**最短路径 ≥ 5 个房间**（不含纯 fork）。
4. 同一分叉的两条线主题应可区分（如「对照加练」vs「剧情旁路」），边要有 `label`。
5. **保底线**始终存在：即使乱选也能到 Boss（避免软锁）。

三层可提高 `combat` 的 `minItems`、提高跨歌比例、Boss 必含 `transfer: true` 题。

## 5. Agent 输出会变多吗？怎么控质量

| 层级 | Agent 产出 | 你的控制 |
| --- | --- | --- |
| 整局 `RunDraft` | `floors[]` → `rooms[]` → `encounter.items[]` | `pathTemplate: p2_spire_three_floors` |
| 房间 | `roomType` + `personaId` + 题包 | `allowedRoomTypes`、`minItems` |
| 题目 | 与现 P0 字段相同 + 可选听辨 | 禁止无证据判血 |
| 状态机 | 通常 **不**由模型算血量 | **B 引擎**根据答对/错结算；Agent 只生成内容 |

**防「又短又水」的硬门槛（建议写入校验）：**

- 整局战斗向房间 ≥ 10
- 每个 `combat` ≥ 4 题；`elite` ≥ 5；`boss` ≥ 6
- 至少 2 层；每层最短路径 ≥ 5
- 题包内证据行不得全部重复同一句（鼓励多句/跨歌）
