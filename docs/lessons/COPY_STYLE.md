# 出题文风（去 AI 味）

生成题干、选项、解释、补教、房间标题时遵守。校验器会对命中禁词的草稿给出 `styleWarnings`（不代替人工抽检）。

## 要

- 短句。一题一事。
- 题干点名具体歌词片段或词。
- 解释只写「句里哪个词推出什么」；不升华、不鸡汤。
- 补教只指路：看哪一句、圈哪个词。
- 房间名用具体场景（窗边、站台），少用抽象口号。

## 不要

- 排比开场：「首先…其次…最后…」
- 空评：「值得注意的是」「综上所述」「在这个语境下我们可以看到」
- 广告腔：「开启学习之旅」「义项扫荡」「深度剖析」「赋能」
- 未证实情绪当唯一答案：「一定在撒娇」「明显很伤心」
- 编造输入里没有的歌词行。

## 长度建议

| 字段 | 上限（字） |
| --- | --- |
| prompt / option | 120 |
| explanation / remedial | 160 |
| room title | 40 |
| contrastAxis | 80 |
