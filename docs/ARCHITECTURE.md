# 架构与信任边界

项目是一个不依赖第三方运行包的 Node.js 本机 HTTP 服务，绑定 `127.0.0.1`，同时提供静态网页和 JSON API。浏览器只保存不透明的会话 ID；离线教学的进度、标准答案和评分逻辑保存在服务进程中。网页刷新可恢复进度，但服务重启后会话失效；持久化仍待实现。

Agent 的课程模型、状态机、自适应规则和验收标准见[歌曲语境学习 Agent 设计](superpowers/specs/2026-11-03-song-context-agent-design.md)。
韩语、日语和中文的学习目标语言、API 兼容与测试边界见[多语言 Agent 扩展设计](superpowers/specs/2026-11-03-multilingual-agent-design.md)。
真实歌曲从同步歌词进入 AI 规划、动态课程和学习会话的链路见[真实歌曲 AI 学习链路设计](superpowers/specs/2026-11-03-real-song-ai-learning-design.md)。
动态关卡生成、音符听辨、NPC 情境题、知识卡和串词成句见[歌曲定制 ASCII 地下城设计](superpowers/specs/2026-11-03-customized-ascii-dungeon-design.md)。

## 模块

- `frontend/`：页面、资料库交互、Discover、浏览器本地音频播放。
- `backend/agent/session.js`：会话状态、节点推进、幂等提交和对外学习视图。
- `backend/agent/curriculum.js`：课程包结构校验、证据检查、当前节点与公开地图投影。
- `backend/agent/evaluation.js`：服务端评分、补教反馈和技能掌握摘要。
- `backend/agent/dungeon-agent.js`：根据歌曲主题、歌词密度与知识节点决定关卡数和每关实体，校验听辨题、NPC 题、知识卡、终局歌词行和字符散布种子。
- `backend/agent/dungeon.js`：把 Agent 设计组装为可达的 19×9 ASCII 地图，处理移动、碰撞、待答题状态、知识卡、经验和串词成句。
- `backend/agent/llm.js`：统一的受信模型调用、HTTPS 地址约束和 JSON 输出错误处理。
- `backend/agent/planner.js`：从真实同步歌词规划可校验知识节点，再调用专用地下城 Agent 生成歌曲定制关卡。
- `backend/agent/model.js`：模型解释；只检查返回结构，无法凭结构校验证明语义正确。
- `backend/env.js`：在服务直接启动时加载本机 `.env`，不覆盖已有环境变量，不记录密钥。
- `backend/media/lyrics.js`：按歌名、歌手和时长匹配 LRCLIB 歌词，解析句级时间戳。
- `backend/media/library-index.js`：读取本机音乐曲目元信息，在内存中临时建立歌词检索索引；不写入可提交缓存。
- `backend/media/mac-music.js`：只在 macOS 加载的 AppleScript 适配器，提供固定的资料库与播放操作。
- `backend/media/system-player.js`：通过 `nowplaying-cli` 读取系统媒体状态并控制当前 QQ 音乐或网易云音乐歌曲；调用前后核对来源与曲目。
- `backend/media/windows-player.js` 与 `windows-media-session.ps1`：在 Windows 上通过系统媒体会话控制 QQ 音乐，通过仅绑定本机的 CEF 调试端口调用网易云既有播放桥；只接受预定义动作和校验后的参数。
- `backend/media/qq-playlist.js`：分页读取 QQ 音乐公开分享歌单，只投影点播和歌词匹配所需的歌曲元数据。
- `backend/media/netease-library.js`：只读网易云 macOS 或 Windows 客户端的本地歌曲列表与歌单缓存，向网页投影最少的歌曲元数据；不复制客户端数据库或账号信息。
- `backend/media/qq-library.js`：只读 QQ 音乐 Mac 客户端的歌曲缓存数据库，只返回学习列表所需元数据；不返回文件路径或账号信息。
- `backend/media/qq-lyrics.js`：按本机歌曲 MID 从 QQ 音乐公开接口获取同步 LRC，核对歌名、歌手和时长，失败时尝试 LRCLIB；标明来源和未人工核对状态。
- `shared/contract.js`：关键跨端对象的运行时校验。
- `shared/languages.js`：韩语 `ko`、日语 `ja`、中文 `zh` 的唯一语言注册表。
- `content/fixtures/demo.js`：原创、可审查的韩中日固定教学样例与课程包。

## 四条数据流

1. **离线演示：**选择学习语言和原创样例歌 → 创建由该歌知识点派生的可变关卡地下城 → 用 WASD/方向键操控 `@` → 踩到 `♪` 自动回听并回答三句歌词听辨题 → 碰触 `?` 回答语境题 → 收集 `✦` 知识卡 → 最后一关循环回听原句并按顺序踩中散落的歌词单字。
2. **Mac「音乐」：**读取当前电脑的歌曲元信息 → 用歌名、歌手和时长寻找同步歌词 → 点击歌词行 → 桥接切歌、定位并核对实际播放位置 → 接近句末时暂停。Discover 临时索引同一歌手的多首歌，返回连续字符命中及上下句；文字命中不是词义结论。
3. **Windows QQ/网易云：**只读导入公开或本机歌单 → 网页向回环服务提交歌曲 ID 与歌单位置 → 固定播放器桥执行点播 → 核对当前曲目 → 获取同步歌词 → 原生定位、播放并在句末暂停。
4. **本地音频：**用户填写歌曲信息 → 服务端检索 LRCLIB → 浏览器显示未核对的时间歌词 → 用户选择自己的音频文件 → 浏览器本地定位、循环或暂停。音频文件不会发给服务端。
5. **真实歌曲 AI 学习：**音乐页取得同步歌词 → 用户点击生成学习地图 → 服务端把歌曲信息和歌词片段发送到本机配置的受信模型 → 规划器校验目标表达、六类节点和证据行 → 动态课程创建会话 → 学习页答题、补教并回听带时间戳的证据 → 课程在内存中过期或服务重启后失效。

## 安全与限制

服务只在本机回环地址提供。浏览器带 `Origin` 的请求必须来自该服务自身页面。Mac 与 Windows 桥接都不接受浏览器提供的脚本文本；Windows 网易云调试端口也只允许本机连接。模型密钥和接口地址来自服务端环境变量；配置者应只使用自己信任的 HTTPS 接口，不向匿名请求提供任意 URL 转发能力。

当前已有韩语、日语和中文三套原创、带证据和前置关系的知识课程，并能生成可实际操控的 ASCII 房间。真实歌曲由专用地下城 Agent 根据歌曲特征决定普通关卡数量、主题、地图布局和 note/npc/card 实体组合；地图工具负责把实体放入可达格子。音符题、NPC 语境题、知识卡、噪声碰撞和固定最后一关的串词成句都由服务端状态机验证。动态课程明确标注 AI 生成、未人工核对，并只在内存中短暂保存。歌词检索和模型调用接受用户明确选择的语言；语言不会从歌曲内容自动识别。

仍缺少：服务重启后的持久学习状态、AI 课程的自动人工质量保证、Discover 中经核对的语义判断、开放式回答与语音评分、逐词原声时间戳，以及可在仓库中分发的商业歌曲媒体。一次 Mac 本机实测确认了短片段定位与暂停，但不保证所有歌曲版本和网络条件都稳定。旧原型仍单独存在，用于对照尚未迁入的教学功能。
